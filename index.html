FAQ

What is the Geniethon deck, exactly?

A self-contained HTML presentation (arrow keys to navigate) built for the Databricks Geniethon. It walks through a real support ticket, shows live Genie conversations answering it in seconds, and ends with the architecture: two Genie spaces, a supervisor agent, and a Slack bot.

How were the Genie spaces trained?

Two notebooks hold the full curriculum: SQL training queries, column metadata, measures, filters, and example questions. A parser deploys them to the Genie spaces, and a Genie MCP server plus a testing skill file handles regression testing. The same loop can be pointed at other industries.

Is the data real?

The questions and workflow are real. Figures shown in the deck come from demo runs and are presented for illustration.

What's the stack?

Databricks (Genie, Unity Catalog metric views, model serving, SQL warehouse), Python, and Slack. The deck itself is one hand-written HTML file, no framework.
