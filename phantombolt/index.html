What that wait looks like

This kind of investigation could be self-served.

DATA-REQ Analytics queue
Open house mailers underperforming, need a breakdown
AE needs performance for four dispensers on open house templates, January 2025 to present. Why is one of them so far behind the others? Estimated effort: 3 working days minimum, roughly 3 to 8 analyst hours. With the usual back and forth, often a week or more before it's truly closed.
Figuring this out is a back and forth: pull the numbers, look, ask the next question. Today every round trip goes through whoever can write the SQL. Genie becomes that person. And to be clear about the boundary: Genie is a librarian, not a professor. It pulls exactly the data you ask for. The analysis, and the decision, are still yours.

How it's built · 2 of 2

Training Genie: the usual way vs ours.

The usual way: clicks

Open the Genie space UI
Add a query title, paste the question, by hand
Fill in metadata for every single column
Repeat, for all 119 queries
Something breaks? Hunt through the UI to find which one
bottleneck: speed and maintenance

Our way: code

One notebook holds everything: SQL, joins, measures, filters, column metadata
The system prompt lives in its own markdown file
space_parser deploys the entire space through the API in one run
Tested through the Genie MCP server inside the code assistant
Wrong answer? Update the notebook, redeploy
full space rebuilt in minutes, version controlled, repeatable for any vertical

13
Genie best practices

Built the way Databricks says to build it.

Gold layer→ 4 UC metric viewsbonus→ Genie spaces→ Supervisor→ Slack+ Databricks Onebonus
✓

Privacy: hidden & excluded columns

First name, last name, and other PII are excluded at the space level. They can never appear in an answer, no matter how the question is phrased.

✓

Usage guidance on every query

All 119 training queries declare their grain, time window, and when to use them.

✓

Measures & filters

Governed measures and parameterized filters, so a rate is computed one way, everywhere.

✓

Consistent aliases & column metadata

Every column carries a description and one canonical alias across both spaces.

✓

SQL join specs & guardrails

Join paths are declared, fan-out traps are guarded, and Genie flags immature matchback data on its own.

✓

One definition per metric

Metric views in Unity Catalog mean everyone in the organization asks the same data and gets the same answer.
